在文档文件夹下将有计划文件夹，本规则针对本项目文档文件夹下计划文件夹生效

## 规则说明 

- **文件夹命名规范**: 文件夹名称使用中文直接描述计划名称
- **文件命名规范**: 文件必须以【{状态}】开头，必须为 md 格式
- **总纲**: 计划文件必须包含总纲、各端、大流程的形式分类

### 状态

计划的状态包含：

- 进行中
- 已完成
- 待开始
- 已取消
- 无需执行
- 归档

归档的计划无需状态表达

### 文件夹结构

- **分类**: 计划是由一个总纲和多个子计划组成
- **文档类型**: 总纲和子计划都是详细的计划细节 md 文档；
- **归档**: 计划全部完成后将收录到归档中全部统一管理

```
docs /
  plans /
    - active
      - 项目详情页 v2.0 改造方案 /
        - 【待开始】00.总纲.md
        - 【待开始】01.节点信息模块改造.md
        - 【待开始】02.节点状态模块改造.md
        - 【待开始】03.历史记录设计.md
    - archive /
      - 项目列表页 v1.0 改造方案 /
```

#### 活跃计划

- 活跃计划用于记录当前正在进行中的计划
- 待开始、进行中都属于活跃计划
- 活跃的计划统一归类于 `/docs/plans/active` 文件夹下

#### 计划归档

- 计划全部完成后收录到归档文件夹`/docs/plans/archive`中

### 文件内容

#### 总纲

总纲用于统筹规划全部任务清晰表达完整计划进展和一览全部记录纲要

#### 子计划

每一个 plan 文件必须为 md 格式包含标准的 plan 文件结构，文件内包含几要素

- 执行状态
- 执行进展
- 执行细节
- 更改时间
- 更改要点
