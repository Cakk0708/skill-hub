## 页面组成结构

页面由组件 TechTableLayout 包裹，内部包含以下组件：

- **TechParticleCanvas**: 酷炫科技粒子背景
- **TechTableToolbar**: 顶部操作条
- **TechTableFilter**: 搜索过滤条
- **TechDataTable**: 核心表格主体
- **TechTablePagination**: 底部统计与分页

### 顶部操作条

顶部操作条包含以下按钮：

- **新增**: 通用
- **删除**: 通常 disable，勾选一条单据以上时显示，用于批量删除单据
- **提交**: 通常 disable，勾选一条单据以上时显示，用于批量提交单据，下拉框包含"提交"、"取消提交"选项，直接点击为提交效果
- **审核**: 通常 disable，勾选一条单据以上时显示，用于批量审核单据，下拉框包含"审核"、"反审核"选项，直接点击为审核效果
- **业务操作**: 通用，用于批量操作单据状态，下拉框包含"禁用"、"启用"选项，直接点击为对应操作
- **导出**: 通用。下拉框包含"导出"、"导入"选项，直接点击为导出效果

### 搜索过滤条

搜索过滤条为组合式条件搜索，可通过点击"新增条件组合"按钮添加多个搜索条件。

#### 按钮介绍

- **字段**: 可搜索字段来自模块 enums 接口返回的 fieldsMetadata 字段列表
- **搜索条件**: 根据枚举接口返回的字段类型描述的字段类型，不同字段类型对应不同的搜索条件
  - **包含**: 仅文本型
  - **不包含**: 仅文本型
  - **等于**: 通用
  - **不等于**: 通用
  - **开头为**: 仅文本型
  - **结尾为**: 仅文本型
  - **大于**: 仅数值类型
  - **小于**: 仅数值类型
  - **早于**: 仅日期类型
  - **晚于**: 仅日期类型
  - **不早于**: 仅日期类型
  - **不晚于**: 仅日期类型
- **筛选值**: 根据搜索条件的不同，筛选值也不同
  - **string**: 输入框
  - **integer**: 输入框
  - **datetime**: 输入框为日期范围选择框
  - **choice**: 对应 enums 接口提供的 options 作为下拉框可选值
- **新增条件组合**: 创建一个新的 字段 + 搜索条件 + 筛选值 的组合
- **查询**: 执行搜索
- **重置**: 重置所有搜索条件
- **保存**: 保存当前搜索条件（缓存到浏览器 localStorage）

#### 缓存方式介绍

缓存方式为 localStorage，key 为 `tech_table_filter_${appName}_${moduleName}`，value 为搜索条件的 JSON 字符串

### 核心表格主体

每个数据表格包含以下列：

- **勾选框**: 用于选择行
- **字段列**: 根据模块 enums 接口返回的 fieldsMetadata 字段列表，name 为展示列名称，visble 为 true 的可展示到列，sortble 为 true 的可列支持排序
- **操作**: 操作列，包含编辑、删除、更多按钮
  - 编辑
  - 删除
  - 更多
    - 复制：通用
    - 禁用: 字段中包含 disbleFlag 且值为 false 时显示
    - 启用: 字段中包含 disbleFlag 且值为 true 时显示
    - 提交: 字段中包含 status 且值为 PENDING 时显示
    - 撤销: 字段中包含 status 且值为 IN_PROGRESS 时显示
    - 审核: 字段中包含 status 且值为 IN_PROGRESS 时显示
    - 反审核: 字段中包含 status 且值为 REVIEWED 时显示
