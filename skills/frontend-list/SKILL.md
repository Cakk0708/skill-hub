## 页面组成结构

页面由组件 TechTableLayout 包裹，内部包含以下组件

- **TechParticleCanvas**: 酷炫科技粒子背景
- **TechTableToolbar**: 顶部操作条
- **TechTableFilter**: 搜索过滤条
- **TechGroupList**: 分组表格主体
- **TechDataTable**: 核心表格主体
- **TechTablePagination**: 底部统计与分页

### 组件使用与样式约束

- 列表区域必须使用项目共享组件承载，不在页面中重写筛选条、分组列表、核心表格或分页块；统一组合 `TechTableLayout`、`TechTableFilter`、`TechGroupList`、`TechDataTable` 和 `TechTablePagination`。
- 字段元数据筛选需要远程关联选择等能力时，使用共享组合组件 `SearchConditions`；旧表格公开属性或事件契约无法直接迁移时，使用 `TechLegacyTableAdapter`。不要在页面中另造筛选器、表格或适配层。
- 页面只通过共享组件公开的属性、事件和插槽传递业务数据与行为，不增加只服务单个页面的视觉配置。
- 不在页面样式中覆盖 `.table-card`、筛选条、表头/表体或分页容器的内边距、间距、尺寸、颜色和边框。标准组件缺少共用样式能力时，应修改共享组件本身，让使用该组件的列表保持一致。

### 顶部操作条

顶部操作条包含以下按钮：

- **新增**: 通用
- **删除**: 通常 disable，勾选一条单据以上时显示，用于批量删除单据
- **提交**: 通常 disable，勾选一条单据以上时显示，用于批量提交单据，下拉框包含"提交"、"取消提交"选项，直接点击为提交效果
- **审核**: 通常 disable，勾选一条单据以上时显示，用于批量审核单据，下拉框包含"审核"、"反审核"选项，直接点击为审核效果
- **业务操作**: 通用，用于批量操作单据状态，下拉框包含"禁用"、"启用"选项，直接点击为对应操作
- **导出**: 通用。下拉框包含"导出"、"导入"选项，直接点击为导出效果

所有模块的顶部操作条按钮都是统一的，不得差异化处理；

### 搜索过滤条

搜索过滤条为组合式条件搜索，可通过点击"新增条件组合"按钮添加多个搜索条件。

#### 按钮介绍

- **字段**: 可搜索字段来自模块 enums 接口返回的 fieldsMetadata 字段列表
- **搜索条件**: 根据枚举接口返回的字段类型描述的字段类型，不同字段类型对应不同的搜索条件
  - **包含**: 仅文本型
  - **不包含**: 仅文本型
  - **等于**: 通用
  - **不等于**: 通用
  - **开头为**: 仅文本型
  - **结尾为**: 仅文本型
  - **大于**: 仅数值类型
  - **小于**: 仅数值类型
  - **早于**: 仅日期类型
  - **晚于**: 仅日期类型
  - **不早于**: 仅日期类型
  - **不晚于**: 仅日期类型
- **筛选值**: 根据搜索条件的不同，筛选值也不同
  - **string**: 输入框
  - **integer**: 输入框
  - **datetime**: 输入框为日期范围选择框
  - **choice**: 对应 enums 接口提供的 options 作为下拉框可选值
- **新增条件组合**: 创建一个新的 字段 + 搜索条件 + 筛选值 的组合
- **查询**: 执行搜索
- **重置**: 重置所有搜索条件
- **保存**: 保存当前搜索条件（缓存到浏览器 localStorage）

#### 缓存方式介绍

缓存方式为 localStorage，key 为 `tech_table_filter_${appName}_${moduleName}`，value 为搜索条件的 JSON 字符串

### 分组表格主体

分组表格主体用于展示分组数据，大部分模块没有分组，只有部分模块有分组；
分组表格主体占左侧独立列；搜索过滤条、核心表格主体、底部统计与分页在右侧主列纵向排列。

布局关系结构如下：
```
- 列表主体（左右布局）
  - 分组表格主体
  - 右侧主列（纵向布局）
    - 搜索过滤条
    - 核心表格主体
    - 底部统计与分页
```

在 `TechTableLayout` 中按以下位置组合：`TechGroupList` 放入 `group-list` 插槽，作为左侧区域独立于 `.table-card`；默认插槽中的搜索过滤条和核心表格放在右侧 `.table-card`；`TechTablePagination` 放入 `footer` 插槽，在右侧主列中紧接表格卡片下方、与表格区同宽。不要把分组列表放进 `.table-card`，也不要让分页横跨分组区和表格区。

每个分组表格包含以下块：

- 分组筛选
- 分组内容（核心表格主体）
  - 全部
  - 子列

### 核心表格主体

每个数据表格包含以下列：

- **勾选框**: 用于选择行
- **字段列**: 根据模块 enums 接口返回的 fieldsMetadata 字段列表
  - name 为展示列名称
  - visble 为 true 的可展示到列
  - sortble 为 true 的可列支持排序
  - fieldType 
    - 为 choice 的列不能直接展示 value，需用 value 值匹配到对应 options 后展示
    - 为 boolean 的直接展示`是`与`否`
- **操作**: 操作列，包含编辑、删除、更多按钮
  - 编辑
  - 删除
  - 更多
    - 复制：通用
    - 禁用: 字段中包含 disbleFlag 且值为 false 时显示
    - 启用: 字段中包含 disbleFlag 且值为 true 时显示
    - 提交: 字段中包含 status 且值为 PENDING 时显示
    - 撤销: 字段中包含 status 且值为 IN_PROGRESS 时显示
    - 审核: 字段中包含 status 且值为 IN_PROGRESS 时显示
    - 反审核: 字段中包含 status 且值为 REVIEWED 时显示

#### 表格交互

- **表格滚动**: 表格内容超出允许高度时，允许横向滚动，但勾选框列与操作列保持固定不参与滚动

### 底部统计与分页

- 统计块
  - 统计数据总数（全页）
  - 统计选中行数
- 分页组件
  - 单页展示数量选择器
  - 页面选择器
    - 上一页
    - 临近页
    - 本页
    - 临近页
    - 下一页
  - 页跳转
