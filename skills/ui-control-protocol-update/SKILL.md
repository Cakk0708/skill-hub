# 常用概念

- **地图文档**: `docs/ui-protocol/map.md `
- **元素布局说明文档**: 有地图文档指向的 `docs/ui-protocol/layouts/` 路径下的对应元素布局说明文档

# UI 控制协议更新 Skill

## 任务目标

当用户说：

- 更新UI控制协议
- 同步UI协议
- 根据当前页面调整更新 design.md

你需要：

1. 读取已有元素布局说明文档
2. 理解当前页面结构（来自本次对话 / 最新描述）
3. 对比新旧结构差异
4. 仅更新发生变化的部分
5. 保持已有路径和命名稳定
6. 将更新后的结果写回元素布局说明文档

---

## 核心原则（必须遵守）

### 原则 1：禁止全量重写

绝对不要：

* 重新生成整个元素布局说明文档
* 覆盖所有节点
* 重排所有结构

只能做：

* 增量修改
* 局部插入
* 局部删除
* 局部替换

---

### 原则 2：路径稳定优先

如果一个节点：

* 语义未变
* 位置未变

即使：

* UI样式变了
* 文案略有变化

👉 **禁止修改它的英文 ID 和路径**

---

### 原则 3：优先复用已有节点

如果新结构中出现类似节点：

* 名称相近
* 位置相近
* 语义相同

👉 应复用原节点，而不是创建新 ID

---

### 原则 4：最小变更原则

只处理以下变化：

* 新增节点
* 删除节点
* 节点重命名
* 节点位置变化
* 节点类型变化

不要改动未受影响部分。

---

## 标准执行流程

---

### 第一步：读取现有协议

必须先读取：

```text
docs/ui-protocol/design.md
```

提取：

* 页面结构树
* 节点映射表
* 已有路径
* 已有 ID

---

### 第二步：解析当前页面结构

从用户当前输入或上下文中提取：

* 新页面结构
* 新增模块
* 删除模块
* 改名节点
* 调整层级

如果用户没有提供完整结构：

👉 只基于“变更描述”推断变化范围

---

### 第三步：结构对比（核心步骤）

你需要做逻辑对比：

#### 1. 新增节点

→ 插入结构树 + 映射表

#### 2. 删除节点

→ 从结构树 + 映射表移除

#### 3. 重命名节点

→ 更新中文名称
→ **保留原英文 ID（优先）**

#### 4. 结构移动

→ 更新父路径
→ 保持 ID 不变

#### 5. 类型变化

→ 更新 type 字段

---

### 第四步：更新文档各部分

只允许更新以下区域：

---

#### ✅ 更新 1：页面结构树

* 插入新增节点
* 删除已移除节点
* 调整层级变化

---

#### ✅ 更新 2：关键节点映射表

* 新增节点 → 添加行
* 删除节点 → 删除行
* 修改节点 → 更新对应字段

---

#### ❌ 不要动：

* 路径规则（除非规则本身改变）
* 定位约束（一般不变）

---

### 第五步：写回文件

```bash
mkdir -p .codex/docs
```

覆盖写入：

```text
.codex/docs/design.md
```

---

## 变更识别规则

---

### 新增节点判断

满足任一：

* 原文档不存在该节点
* 当前结构中新增模块/按钮/输入框

→ 视为新增

---

### 删除节点判断

满足：

* 原文档存在
* 当前结构明确已删除

→ 从文档中移除

---

### 重命名判断

满足：

* 位置相同
* 类型相同
* 语义相同但名称变化

例如：

```text
登录验证（按钮） → 登录（按钮）
```

👉 只改中文名称，不改 ID

---

### 冲突处理

如果出现：

* 同一位置两个相似节点
* 无法判断是否复用

优先策略：

1. 保留旧节点
2. 新节点作为新增
3. 不随意覆盖旧节点

---

## 输出限制（必须遵守）

---

### 禁止行为

* ❌ 重新生成完整文档
* ❌ 改写全部 ID
* ❌ 改写全部路径
* ❌ 重排整个结构树
* ❌ 删除未明确移除的节点
* ❌ 添加与当前页面无关内容
* ❌ 增加解释性段落

---

### 必须保持

* 原有文档结构（4大块）
* 原有 ID 稳定
* 原有路径稳定
* 原有未变化节点不动

---

## 示例

---

### 输入

```text
更新UI控制协议

变更：
- 登录页新增“记住我（复选框）”
- Step 03 删除“重新开始（按钮）”
- 登录验证按钮改名为“登录”
```

---

### 正确行为

#### 1. 在结构树中：

* 登录页 → 新增 `记住我（复选框）`
* Step 03 → 删除 `重新开始（按钮）`

#### 2. 在映射表中：

* 新增：

```text
记住我（复选框） → remember_me_checkbox
```

* 删除：

```text
restart_button
```

* 更新：

```text
登录验证（按钮） → 登录（按钮）
（ID 保持 login_submit_button）
```

---

## 成功标准

当本 skill 执行完成后：

* 元素布局说明文档被正确更新
* 未变更部分完全保持不动
* 新增/删除/修改准确反映
* 所有路径仍然可用
* Codex 后续仍可用该文档做精准定位
