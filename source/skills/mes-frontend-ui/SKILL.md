# MES 前端界面设计

本 skill 适用于页面或组件的视觉设计与交互调整。纯请求、状态和数据逻辑改动不需要加载本 skill。

## 设计基线

- 延续 MES 管理系统的企业应用风格和信息密度，优先检查所在页面、相邻模块、共享组件和全局 tokens。
- 优先复用 Element Plus 组件、项目公共组件和 UnoCSS 工具类；需要改全局视觉时先检查影响范围。
- 当前主题以蓝色主色、深色导航和浅色内容区域为主。优先复用 `frontend/src/settings.js`、`frontend/src/styles/variables.scss` 中的设置和变量，不要另建冲突的颜色、字体或间距体系。
- 字体、圆角、控件高度、表格密度等遵循现有页面和组件；不强制胶囊按钮、固定圆角、粗体正文或游戏化插画。
- 页面是否支持移动端由具体需求决定，不为了通用规则压缩复杂表格或仓储操作流程。

## 视觉与交互

- 使用颜色表达明确语义：主操作、成功、警告、错误和禁用状态应可区分，并满足可读性。
- 表格、筛选区和表单优先保持对齐、层级清楚和足够的信息密度。
- 保留键盘操作、可见焦点和必要的无障碍状态；不要用全局移除 `outline` 的方式隐藏焦点。
- 动效只用于解释状态变化或提供必要反馈；支持 `prefers-reduced-motion`。
- 新建页面时先复用相邻业务模块已有的布局、颜色和交互，再引入新的视觉样式。
- 修改登录页、报表、看板或设备大屏时，遵循该页面自己的设计目标，不把后台列表页规范机械套用过去。

## 检查

- 主要操作和禁用、错误、成功状态容易区分。
- 表格、输入项、按钮在当前页面密度下清晰可用。
- 交互有键盘焦点和必要状态反馈。
- 样式尽量复用现有 tokens 和组件，没有改变不相关页面的全局表现。
