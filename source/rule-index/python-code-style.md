## Python 代码格式规范

- 遵循项目现有 formatter、linter 和相邻代码的格式；不要因本规则重排或格式化无关代码。
- 新增代码保持清晰的空行和一致的缩进，并遵循项目配置的行宽。
- 类名使用 PascalCase；变量、函数和模块名遵循 Python 与项目现有命名约定。
- 仅在逻辑不易理解、需要说明原因或记录必要 workaround 时添加注释；不要求为显然的代码补注释或为每个模块添加固定格式的文件头。
